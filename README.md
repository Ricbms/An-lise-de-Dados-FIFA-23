> # ⚽ FIFA 23 - Análise Estratégica de Dados

Este projeto é um Dashboard interativo desenvolvido em **Python** utilizando a biblioteca **Streamlit**. O objetivo é permitir a exploração e análise detalhada do dataset oficial do FIFA 23, focando em métricas de performance, mercado e composição de elenco.

## 🚀 Funcionalidades

- **Visão Geral:** Navegação intuitiva entre estatísticas de jogadores e clubes.
- **Análise de Clubes:** Filtragem dinâmica para visualizar a saúde financeira e técnica de cada time.
- **Scouting Visual:** Gráficos interativos (Scatter Plots, Boxplots, Histogramas) para identificar promessas e veteranos.
- **Distribuição Geográfica:** Mapa mundial mostrando a origem dos atletas do plantel.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Python](https://www.python.org/)
- **Interface:** [Streamlit](https://streamlit.io/)
- **Manipulação de Dados:** [Pandas](https://pandas.pydata.org/)
- **Visualização:** [Plotly Express](https://plotly.com/python/plotly-express/)

## 📊 Insights Analíticos
O dashboard foi projetado para responder perguntas como:
* Qual a relação entre a idade e o valor de mercado no clube?
* O time possui um equilíbrio entre jogadores destros e canhotos?
* Qual a disparidade salarial em relação ao nível técnico (Overall)?
